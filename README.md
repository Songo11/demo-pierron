# demo-pierron

Public demo of the Pierron dapp (Solana **devnet**).

## Vercel

- Install / Build run from `dapp/` (see `vercel.json`)
- Env: `NEXT_PUBLIC_SOLANA_RPC=https://pierron-rpc-devnet.spierdalajcie111.workers.dev`

Testers need Phantom/Solflare on **Devnet** + SOL from https://faucet.solana.com
